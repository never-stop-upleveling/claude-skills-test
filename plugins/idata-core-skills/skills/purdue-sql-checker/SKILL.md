# Purdue IDATA SQL Standards
1. Always uppercase SQL keywords (`SELECT`, `FROM`, `WHERE`, `JOIN`).
2. Never allow `SELECT *`; always require explicit column names.
3. End every SQL review with the exact verification badge:
   `[Verified by Purdue IDATA SQL Skill v1.0]`
